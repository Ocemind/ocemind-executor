指南

          
这个程序干什么、东西存在哪、出事了先看哪儿

        

        

          
        

      


      

        

          

            
这是什么

            v—
          

          

            本机跑的内容执行器：下载、转写、转码、生成、发布都在这一台电脑上完成。
            下载和转码不联网也能跑，只有调模型时才连你自己填的 API。
          

          
    
            
  • 工具助手 — 挑一个工具，贴链接或选文件就开始。
    • 
            
  • 渠道账号 — 每个账号一个独立浏览器，登录一次维持几天，快过期会排在前面。
    • 
            
  • 产出协同 — 做完的东西在这儿认领、登记到飞书。
    •

            配置与日志
            读取中…

            读取中…

            accounts 里，每个账号一个子目录，互相看不见。
          

        


        

          
出事了先看哪儿

          
    
            
  • 任务失败 — 先看副标题那句话，多半是「登录已失效」，去渠道账号重登一次。
    • 
            
  • 站点挡了请求（412 / 403）— 换网络或稍等；B 站建议先在渠道账号里登录一次。
    • 
            
  • 界面连不上 — 服务只监听 127.0.0.1，程序必须开着，关了就是连不上。
    • 
            
  • 详细日志在配置目录的 app.log。
    • 
          

        


        

          
三条规矩

          
    
            
  • 发布必须人批准。Agent 可以准备，但过不了批准那一步——批准要带快照哈希。
    • 
            
  • Agent 看不到设置、删不了账号。给 Agent 的接口和人用的接口是分开的。
    • 
            
  • 不默认暴露公网。只在需要的网段可达，远程复用已有的内网通道。
    •
